# Caso de trabajo (ficticio)

La Academia Horizonte gestiona matrículas mediante una plataforma web. La campaña dura
siete días. Su objetivo es que las solicitudes puedan completarse dentro del plazo y que
los registros confirmados se conserven y puedan recuperarse.

**Activos:** plataforma web, base de datos de matrículas y copias de seguridad.

## Condiciones conocidas

- Hay una única instancia de base de datos y no se ha probado la restauración de las copias.
- La cuenta que utiliza la aplicación tiene permisos administrativos sobre la base de datos.

Estas condiciones pertenecen al caso ficticio. No describen la configuración real de
nuestro proyecto.
